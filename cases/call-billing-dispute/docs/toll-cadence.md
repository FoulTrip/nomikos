# Toll cadence policy (calls)

§1 One request per minute: each settled minute returns the invoice
for the next minute. The caller drives the cadence.

§2 Price: 1000 lamports per minute, fixed for the whole call.

§3 Ended calls accrue no further tolls. Minutes already settled
are never re-billed.
